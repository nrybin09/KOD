# Моделирование НКА

Настольное приложение для чтения навигационных файлов GPS/ГЛОНАСС, расчёта
положения НКА, отображения графиков и экспорта результатов.

## Запуск

Из корня проекта:

```powershell
python main.py
```

`main.py` — единственная точка запуска программы.

Зависимости и минимальная версия Python указаны в `pyproject.toml`. Установка:

```powershell
python -m pip install .
```

## Структура

В корне находятся только точка запуска, конфигурация проекта и рабочие данные:

- `main.py` — создаёт Qt-приложение и открывает главное окно;
- `pyproject.toml` — описание проекта и список зависимостей;
- `data/` — входные навигационные файлы;
- `maps/` — локальная картографическая подложка;
- `export/` — результаты выполненных экспериментов;
- `nka_app/` — весь исходный код приложения.

## Модули `nka_app`

- `common.py` — общие импорты, физические константы и пути проекта;
- `models.py` — модели записей, настроек, точек и эксперимента;
- `navigation.py` — загрузка данных и единый вызов расчётных модулей;
- `editing.py` — проверка и применение изменений параметров таблицы;
- `worker.py` — фоновое выполнение расчётов;
- `main_window.py` — главное окно и управление сценарием работы;
- `navigation_table.py` — таблица параметров и закреплённые `az/el`;
- `theme.py` — шрифт и настройки оформления;
- `sky.py` — небесная карта;
- `trajectories.py` — карта Земли, 3D и графики `az/el`;
- `coordinates.py` — преобразования BLH/XYZ и WGS84/ПЗ-90.02;
- `parse_eph_gps.py`, `parse_eph_glonass.py` — парсеры эфемерид;
- `parse_alm_gps.py`, `parse_alm_glonass.py` — парсеры альманахов;
- `math_eph_gps.py`, `math_eph_glonass.py` — расчёты по эфемеридам;
- `math_alm_gps.py`, `math_alm_glonass.py` — расчёты по альманахам;
- `exporter.py` — экспорт TXT и описания эксперимента;
- `__init__.py` — обозначает `nka_app` как обычный пакет Python.
